<h2>📖 Sobre este portafolio</h2>

> Este repositorio reúne el trabajo de las 150 horas del módulo
> <strong>Programación web en el entorno cliente</strong>. Le agrego JavaScript a los sitios
> que construí en el módulo de Codificación de páginas web: <strong>Luz Clara</strong>, el
> proyecto de clase (<code>luz-clara/</code>, prácticas guiadas), y <strong>Casa Tomillo</strong>,
> mi AC3 (<code>casa-tomillo/</code>, prácticas autónomas). Cada carpeta de unidad guarda los ejercicios cortos de
> cada clase y el registro de evidencias documenta qué hice y qué aprendí.
